## FLASH compatibility decisions

The native-tab workspace adapter remains the source of sidebar session selection.
Creating a sidebar session must not turn it into a standalone window or cascade
the existing workspace. Hidden-titlebar standalone windows retain upstream's
show-before-cascade behavior. File-browser and sidebar visibility inheritance
remain intact.

Close Window captures its original session set. Review focuses each busy session
through the workspace adapter, supports cancellation, and closes the originally
captured idle sessions after accepted busy sessions. It does not accidentally
include sessions created after the confirmation opened.

FLASH's macOS defaults remain selection-to-system-clipboard and middle-click
system-clipboard paste. User overrides still win. The old `primary-paste` value
is normalized to `clipboard-paste` on macOS during parsing; empty middle-click
configuration also resets to the compatible macOS default. Linux keeps its
selection-clipboard semantics. The fork's AppleScript dictionary is updated
alongside upstream's separate dictionary.

The new native page-pool teardown path released backing buffers that reset
previously reused. For active-area layouts that fit pooled pages, reset now
retains only the required reusable buffers and still directly releases excess
history pages. Regression tests deny further page allocations during repeated
reset, including after compact has moved an active page to heap storage. This
does not claim to fix the pre-existing allocation behavior of exceptionally
wide, heap-only active-area layouts.

Snapshot tests cover allocated palette ownership, independent restored palettes,
and cleanup after allocation failure. The snapshot format, saved pin identities,
content generations, and product identity/update-channel isolation are retained.

`macos/build.nu` now preserves an explicitly supplied `DEVELOPER_DIR` through its
otherwise clean environment, allowing per-command Xcode selection without
changing the machine's global `xcode-select` setting.
